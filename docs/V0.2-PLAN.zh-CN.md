# v0.2 改进清单与验收标准

本文件记录实际进展，不代表 v0.2 已完成或获得监管认可。

## 已完成：第一批可靠性与报告证据改进

- [x] 拒绝 NaN、正负无穷值；回归测试覆盖三类非有限数。
- [x] 将 YYYYMM 与 YYYY-MM 作为同一月份检查重复记录。
- [x] 对字段数量不一致的记录报告错误，避免额外字段引发崩溃。
- [x] 对实际解析的同一份文件字节计算 SHA-256，记录字节数、UTC 检查时间、工具版本、规则版本；空文件同样保留证据。
- [x] HTML/JSON 报告包含受影响的不同记录数，避免把问题数量当成记录数。
- [x] 报告明确说明：没有发现问题不等于数据正确或合规；导出仅规范化列与部分格式，不自动修正异常。
- [x] 10 项自动测试通过。覆盖检查后原文件被修改，导出仍保留原检查证据。

## 下一批：规则覆盖与真实数据验证

- [ ] 每条规则提供检查状态：已执行／跳过及原因。缺必需列时避免连带产生误导性字段错误。
- [ ] 检查重复列名及别名冲突，禁止静默覆盖。
- [ ] 将真实公开 SCMD 数据与官方当期说明逐项核对，记录获取日期、文件哈希、规则结果及人工复核结论。
- [ ] 区分官方格式约束与项目自定义筛查启发式，不把启发式称为官方标准。
- [ ] GUI 展示覆盖情况与受影响记录数，人工检查中英文界面。
- [ ] 验证大文件内存占用、响应时间与取消行为。当前为内存处理，字节快照会增加内存需求。
- [ ] 检查导出覆盖提示、编码报错及 HTML 特殊字符显示。

## 发布门槛

真实数据验证记录、规则覆盖状态、界面人工检查完成后，才发布完整 v0.2。
