# Local maintenance review / 本地维护检查

Status: local candidate `0.4.0a5`; not published. / 状态：本地候选版 `0.4.0a5`，尚未发布。

## Fixed / 已修复

Malformed thousands separators such as `1,2` were previously converted to `12`. Numeric checks now accept finite decimal/exponent notation and properly grouped thousands separators only. The SQL importer uses the same parser, so malformed amounts remain invalid/NULL rather than entering known-cost totals. Source text is retained.

此前 `1,2` 会被误读为 `12`。现在只接受有限的十进制、科学计数法与正确的千位分隔符；SQL 导入共用此逻辑，格式错误的金额保留为无效值/NULL，不计入有效费用汇总。原始文本保留。

## Evidence / 验证

- 42 checker tests and 17 analysis tests passed locally, including malformed-separator, SQLite cost-status, unit-isolation and truncated-CSV CLI regressions. / 本地 42 项检查器测试、17 项分析测试通过，包含错误分隔符、SQLite 费用状态、单位隔离与截断 CSV 命令行回归。
- Both Windows executables passed their packaged diagnostics before and after ZIP extraction. / 两个 Windows 程序在打包后及 ZIP 解压后均通过诊断。

This is build-machine testing, not an independent clean-machine test, external user feedback, or a regulatory validation. Public downloads still point to the earlier release. / 以上为构建机器测试，不是另一台全新机器测试、外部用户反馈或法规验证；公开下载仍指向旧版。

## Additional fixes / 后续修复

Quantity medians no longer combine different or unknown units. The analysis CLI reports truncated CSVs as operational failures without creating an output folder. Candidate builds can use a fresh `--artifact-root` without replacing earlier artifacts. / 数量中位数不再混用不同或未知单位；分析命令行明确提示截断 CSV 失败，不创建结果目录；候选构建可指定新的 `--artifact-root`，保留之前产物。
