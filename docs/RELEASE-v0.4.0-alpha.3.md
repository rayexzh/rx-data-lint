# RxDataLint v0.4.0-alpha.3 — Grouped review / 分组复核

**English.** Download and fully extract the Windows ZIP, then run `Start-Checker.bat`. The checker now groups the current findings by rule, organisation or medicine. Select a group to inspect its source rows; filtered JSON exports record the exact group. The SQL analysis program is unchanged. Findings are review prompts, not confirmed data errors. The public July 2026 provisional SCMD file (319,345 rows) was used to check the workflow. All 38 checker tests and 15 analysis tests passed; built and extracted executables passed packaged diagnostics. The executable is unsigned and has not been verified on an independent Windows computer.

**中文。** 下载并完整解压 Windows ZIP，打开 `Start-Checker.bat`。检查器现可按规则、机构或药品汇总当前提示，进入某组查看对应原始行；筛选 JSON 会记录分组范围。SQL 分析程序未改变。提示是复核线索，不等于已确认错误。使用公开的 2026 年 7 月临时版 SCMD 文件（319,345 行）核查流程。38 项检查器测试和 15 项分析测试通过，打包目录及解压后的 EXE 自检通过。EXE 未签名，尚未在独立 Windows 电脑验证。
